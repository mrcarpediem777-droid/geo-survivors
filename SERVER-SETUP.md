# Как включить сервер

Это единственный документ в проекте по-русски, потому что по нему **ты кликаешь
сама**. Всё остальное — мои заметки.

Пока ты этого не сделаешь, **игра работает ровно как раньше**: здания покупаются
и остаются твоими, просто их никто не видит и никто не может перекупить. Ничего
не сломается и ничего не потеряется.

Займёт минут десять. Платить не надо: бесплатного тарифа хватит на тысячи
игроков.

---

## Шаг 1. Завести базу данных

1. Открой **supabase.com** и нажми Start your project. Войти можно через GitHub —
   он у тебя уже есть.
2. Нажми **New project**.
   - Name: `geo-survivors`
   - Database Password: нажми Generate, **скопируй и сохрани где-нибудь у себя**.
     Он нам не понадобится, но восстановить его нельзя.
   - Region: выбери ближайший к игрокам. Для Вьетнама — Singapore.
3. Нажми Create new project и подожди минуту-две, пока он поднимется.

## Шаг 2. Создать таблицу

1. Слева в меню открой **SQL Editor**.
2. Вставь целиком то, что ниже, и нажми **Run**.

```sql
-- Единственная таблица во всей игре. Хранит только то, ЧТО ЛЮДИ СДЕЛАЛИ:
-- какое здание кому принадлежит и сколько за него заплачено.
-- Ни координат людей, ни времени, ни истории перемещений здесь нет и не будет.
create table if not exists buildings (
  key           text primary key,
  lat           double precision not null,
  lng           double precision not null,
  owner_device  text not null,
  owner_name    text not null,
  paid          integer not null,
  bought_at     timestamptz not null default now()
);

-- Чтобы «что тут вокруг» работало быстро, когда зданий станут тысячи.
create index if not exists buildings_position on buildings (lat, lng);

-- Никто снаружи не может читать и писать эту таблицу напрямую.
-- Ходить в неё имеет право только наш сервер, своим отдельным ключом.
alter table buildings enable row level security;
```

Должно написать **Success**. Если ругается — пришли мне текст ошибки целиком.

## Шаг 3. Взять два значения

1. Слева внизу **Project Settings** → **API**.
2. Оттуда нужны два поля:
   - **Project URL** — выглядит как `https://что-то.supabase.co`
   - **service_role** — длинная строка. Нажми Reveal, чтобы увидеть.

⚠️ **`service_role` — это ключ от всей базы.** Не публикуй его нигде, не
вставляй в переписку, не клади в код. Он живёт только в настройках Vercel. Если
он всё-таки куда-то утёк — на той же странице есть кнопка сбросить его.

## Шаг 4. Отдать их сайту

1. Открой **vercel.com**, свой проект **geo-survivors**.
2. **Settings** → **Environment Variables**.
3. Добавь две штуки:

   | Name | Value |
   |---|---|
   | `SUPABASE_URL` | Project URL из шага 3 |
   | `SUPABASE_SERVICE_KEY` | service_role из шага 3 |

   Обе — для всех окружений (Production, Preview, Development).
4. **Deployments** → у верхнего нажми «…» → **Redeploy**. Без этого новые
   настройки не подхватятся.

## Шаг 5. Проверить

Открой в браузере:

```
https://geo-survivors.vercel.app/api/ledger?lat=0&lng=0&radius=1
```

- Было до настройки: `{"configured":false}`
- Должно стать: `{"configured":true,"entries":[]}`

Если так — готово. Игра сама это заметит при следующем открытии, и здания станут
общими.

## Что теперь может пойти не так

**Ты покупаешь здание, а его уже кто-то купил.** Так и задумано: чтобы отобрать,
надо заплатить больше, чем заплатил он. Игра скажет, сколько именно.

**Нет связи.** Купить нельзя, играть можно. Игра не сломается и не соврёт —
скажет «нет сигнала, попробуй, когда вернёшься в зону».

**Кто-то попробует смухлевать.** Сейчас телефон сам говорит серверу, сколько у
него монеток, и сервер верит. Пока играешь ты одна — это ничего не стоит. Как
только людей станет больше одного, монетки надо будет считать на сервере, а не на
телефоне. Это следующая работа, и я про неё не забуду.

---

## Что сервер про людей знает

Только это:

- какое здание кому принадлежит и сколько заплачено;
- случайная метка телефона (не имя, не почта, не номер);
- имя, которое человек сам себе выбрал.

Чего он **не знает и не узнает**: где человек ходит, когда он там был, сколько
прошёл. Этот журнал остаётся на его телефоне и никуда не отправляется.

Причина простая: здание, которое человек купил, обычно рядом с его домом. Список
«кто чем владеет и когда купил» — это инструмент, которым ищут людей. Поэтому его
не будет.
