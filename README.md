# Geo-Survivors

A Vampire-Survivors-style swarm game played directly on a real map of your actual
surroundings. Real building footprints are walls. Real streets are the corridors
you fight in.

**Start here: [PLAYBOOK.md](PLAYBOOK.md)** — written for a non-programmer.

- [TUNING.md](TUNING.md) — every number that changes how the game feels
- [MONETIZATION.md](MONETIZATION.md) — every paid hook, and why each grants convenience not power

## Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:5173

Built with Vite + TypeScript + MapLibre GL JS. Map data © OpenStreetMap contributors.
